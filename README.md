# Module 4: React Profile Card Application

A React + TypeScript app built with Vite that displays a student directory using reusable components and typed props.

## Components
- `Header` — displays the course title
- `StudentCard` — reusable card component with typed props (`name`, `major`, `graduationYear`)
- `Footer` — displays a closing message

## Setup
```
npm install
```

## Run
```
npm run dev
```
